# Trabajo-de-integrador

## Ejecutar la aplicación

Desde esta carpeta, activa el entorno virtual del proyecto e inicia `main.py`:

```powershell
..\.venv\Scripts\Activate.ps1
python main.py
```

No ejecutes los archivos de `gui` directamente. El video de inicio está en
`assets\splash.mp4`; las fotos subidas para el catálogo se guardan en
`assets\catalogo`.

## Orden de registro

1. Crea una cuenta desde la pantalla de inicio de sesión.
2. Inicia sesión y registra una finca.
3. Registra una vaca, selecciona su foto con **Subir foto** y marca
   **Publicar en catálogo** para que aparezca en el catálogo.
4. Registra medicamentos y producción para una vaca ya registrada.
5. La alimentación puede registrarse como general o asignarse a una vaca.
